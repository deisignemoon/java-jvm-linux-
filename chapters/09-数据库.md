## 数据库

### 表达式与SQL的关系

数据库中，**表达式通常指"关系代数表达式"**，SQL 是它的**具体实现/等价转换**。二者关系是：**关系代数表达式的每一步操作都对应一条 SQL 子句**，可以相互转换。

| 关系代数 | SQL |
| --- | --- |
| π (投影 projection) | SELECT 列名 |
| σ (选择 selection) | WHERE 条件 |
| ⋈ (连接 join) | JOIN / FROM + ON 条件 |
| × (笛卡尔积) | CROSS JOIN |
| ∪ (并) | UNION |
| − (差) | EXCEPT/MINUS |
| ÷ (除) | NOT EXISTS 嵌套查询 |

核心考点：能写出某关系代数表达式的等价 SQL，或反之；以及"任何 SQL 查询的本质都是基于关系代数运算"。

记忆口诀：**"π 对 SELECT，σ 对 WHERE，⋈ 对 JOIN，∪ 对 UNION"**
