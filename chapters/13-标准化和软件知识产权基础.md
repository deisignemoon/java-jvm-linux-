# 标准化和软件知识产权基础

## 1. 标准化基本概念

### 1.1 标准化的定义
标准化是指为在一定的范围内获得最佳秩序，对活动或其结果规定共同的和重复使用的规则、导则或特性的活动。

### 1.2 标准化的目的
- 改进产品、过程或服务的适用性
- 促进技术合作
- 防止贸易壁垒
- 保护消费者利益
- 保护环境

### 1.3 标准化的作用
- **技术保障**：为产品质量提供技术依据
- **贸易基础**：消除贸易壁垒，促进国际贸易
- **依法管理**：为依法管理提供技术依据
- **保护安全**：保障人体健康和人身财产安全

## 2. 标准分类

### 2.1 按层级分类
| 层级 | 说明 | 示例 |
|------|------|------|
| 国际标准 | ISO、IEC制定 | ISO 9001 |
| 国家标准 | GB（中国）、ANSI（美国） | GB/T 19001 |
| 行业标准 | 行业主管部门制定 | SJ/T（电子行业） |
| 地方标准 | 省级标准化主管部门 | DB11（北京） |
| 企业标准 | 企业内部制定 | Q/XXX |

### 2.2 按性质分类
- **强制性标准**：GB（必须执行）
- **推荐性标准**：GB/T（自愿采用）

### 2.3 按对象分类
- **技术标准**：对标准化领域中需要协调统一的技术事项
- **管理标准**：对标准化领域中需要协调统一的管理事项
- **工作标准**：对工作的责任、权利、范围等所做的规定

## 3. 软件工程标准

### 3.1 软件生存周期过程标准
- **ISO/IEC 12207**：软件生存周期过程
- **GB/T 8566**：信息技术 软件生存周期过程

### 3.2 软件质量标准
- **ISO/IEC 9126**：软件质量模型
- **ISO/IEC 25010**：系统和软件质量要求和评价

### 3.3 软件文档标准
- **GB/T 8567**：计算机软件文档编制规范
- **GB/T 9385**：计算机软件需求规格说明规范
- **GB/T 9386**：计算机软件测试文档编制规范

### 3.4 软件过程标准
- **CMMI**：能力成熟度模型集成
- **ISO/IEC 15504**：信息技术 过程评估

### 3.5 软件项目管理标准
- **ISO/IEC 10006**：质量管理 项目质量管理指南

## 5. 知识产权基础

### 5.1 知识产权的概念
知识产权是智力成果的创造人依法所享有的权利和生产经营活动中标记所有人依法所享有的权利的总称。

### 5.2 知识产权的分类
```
知识产权
├── 著作权（版权）
│   ├── 软件著作权
│   └── 文学艺术作品
├── 专利权
│   ├── 发明专利
│   ├── 实用新型专利
│   └── 外观设计专利
├── 商标权
│   └── 商品商标、服务商标
└── 商业秘密
    ├── 技术秘密
    └── 经营秘密
```

### 5.3 知识产权的特点
- **专有性**：独占性和排他性
- **地域性**：在特定国家/地区有效
- **时间性**：有法定保护期限
- **无形性**：智力成果是无形的

## 6. 软件著作权

### 6.1 软件著作权的主体
- **开发者**：实际开发软件的个人或单位
- **继受者**：通过继承、转让等方式获得著作权的人

### 6.2 软件著作权的客体
计算机程序（源程序和目标程序）及其有关文档。

### 6.3 软件著作权的内容
| 人身权 | 财产权 |
|--------|--------|
| 发表权 | 复制权 |
| 署名权 | 发行权 |
| 修改权 | 出租权 |
| 保护作品完整权 | 信息网络传播权 |
| | 翻译权 |
| | 许可使用权 |
| | 转让权 |

### 6.4 软件著作权的归属
- **一般原则**：归属于软件开发者
- **职务软件**：归单位所有
- **委托开发**：有约定从约定，无约定归受托人
- **合作开发**：有约定从约定，无约定归合作方共有

### 6.5 软件著作权的保护期
- **自然人**：作者终生及死后50年
- **法人/非法人组织**：首次发表后50年

### 6.6 软件登记
- 软件著作权自开发完成之日起自动产生
- 登记采取自愿原则
- 登记是提起诉讼的前提条件

## 7. 专利权

### 7.1 专利权的主体
- **发明人/设计人**：对发明创造做出实质性贡献的人
- **申请人**：有权申请专利的人
- **专利权人**：享有专利权的人

### 7.2 专利权的客体
| 类型 | 保护对象 | 保护期限 |
|------|----------|----------|
| 发明专利 | 新的技术方案 | 20年 |
| 实用新型 | 产品形状/结构 | 10年 |
| 外观设计 | 产品外观 | 15年 |

### 7.3 授予专利的条件
- **新颖性**：不属于现有技术
- **创造性**：有突出的实质性特点和显著进步
- **实用性**：能够制造或使用并产生积极效果

### 7.4 不授予专利的情况
- 科学发现
- 智力活动的规则和方法
- 疾病的诊断和治疗方法
- 动物和植物品种
- 原子核变换方法和用该方法获得的物质
- 对平面印刷品的图案、色彩或其结合作出的主要起标识作用的设计

## 8. 商标权

### 8.1 商标的概念
商标是商品或服务的提供者为了将自己的商品或服务与他人相区别而使用的标记。

### 8.2 商标注册原则
- **申请在先原则**：先申请者获得商标权
- **自愿注册原则**：是否注册由当事人自主决定
- **强制注册**：烟草制品必须使用注册商标

### 8.3 商标注册条件
- 具有显著性
- 不得与他人在先取得的合法权利相冲突
- 不得使用法律禁止使用的标志

### 8.4 商标权的保护期
- 有效期：10年
- 可无限续展：每次10年

## 9. 商业秘密

### 9.1 商业秘密的构成要件
- **秘密性**：不为公众所知悉
- **价值性**：具有商业价值
- **保密性**：权利人采取了相应保密措施

### 9.2 商业秘密的保护
- 合同约定保护
- 竞业限制协议
- 保密协议
- 侵权诉讼

## 10. 侵权与救济

### 10.1 软件著作权侵权
- 未经许可复制或传播软件
- 破解软件技术保护措施
- 删除或修改软件权利管理信息

### 10.2 专利权侵权
- 未经许可实施他人专利
- 假冒他人专利
- 以非专利产品冒充专利产品

### 10.3 救济方式
- **民事诉讼**：停止侵权、赔偿损失
- **行政投诉**：请求行政部门处理
- **刑事诉讼**：情节严重的追究刑事责任

### 10.4 赔偿计算
- 实际损失
- 侵权获利
- 许可使用费的合理倍数
- 法定赔偿（1万-100万元）

## 11. 常见考点

### 11.1 标准代号含义
| 代号 | 含义 |
|------|------|
| GB | 国家标准（强制性） |
| GB/T | 国家标准（推荐性） |
| GB/Z | 国家标准化指导性技术文件 |
| DB | 地方标准 |
| Q/ | 企业标准 |
| SJ/T | 电子行业推荐性标准 |

### 11.2 保护期记忆
- 软件著作权（自然人）：50年（死后）
- 软件著作权（单位）：50年（首次发表）
- 发明专利：20年
- 实用新型：10年
- 外观设计：15年
- 商标：10年（可续展）

### 11.3 著作权与专利权的区别
| 区别项 | 著作权 | 专利权 |
|--------|--------|--------|
| 取得方式 | 自动取得 | 需申请审批 |
| 保护期限 | 较长 | 较短 |
| 保护条件 | 独创性 | 新颖性、创造性、实用性 |
| 保护对象 | 表达形式 | 技术方案 |

### 11.4 职务作品与职务发明
| 类型 | 著作权/专利权归属 |
|------|-------------------|
| 一般职务作品 | 作者享有，单位有使用权 |
| 特殊职务作品 | 单位享有 |
| 职务发明 | 单位享有 |
| 委托发明 | 有约定从约定，无约定归受托方 |
