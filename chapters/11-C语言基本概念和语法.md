# C语言基本概念和语法

## 1. C语言概述

### 1.1 C语言特点
- **简洁紧凑**：关键字少，语法简洁
- **运算符丰富**：34种运算符
- **数据类型丰富**：整型、浮点型、字符型、数组、指针、结构体等
- **结构化语言**：支持顺序、选择、循环结构
- **可移植性好**：可直接访问物理地址
- **生成代码效率高**

### 1.2 C语言程序结构
```c
#include <stdio.h>  // 预处理指令

int main()          // 主函数
{
    printf("Hello, World!\n");  // 语句
    return 0;       // 返回值
}
```

## 2. 数据类型与运算符

### 2.1 基本数据类型
| 类型 | 关键字 | 字节数 | 范围 |
|------|--------|--------|------|
| 整型 | int | 4 | -2^31 ~ 2^31-1 |
| 短整型 | short | 2 | -32768 ~ 32767 |
| 长整型 | long | 4 | -2^31 ~ 2^31-1 |
| 无符号整型 | unsigned int | 4 | 0 ~ 2^32-1 |
| 单精度浮点 | float | 4 | ±3.4e38 |
| 双精度浮点 | double | 8 | ±1.7e308 |
| 字符型 | char | 1 | -128 ~ 127 |

### 2.2 常量与变量
```c
// 常量
#define PI 3.14159
const int MAX = 100;

// 变量
int age = 25;
float salary = 8500.50;
```

### 2.3 运算符
- **算术运算符**：+、-、*、/、%、++、--
- **关系运算符**：==、!=、>、<、>=、<=

## 3. 控制结构

### 3.1 选择结构
```c
// if-else语句
if (score >= 90)
    printf("优秀");
else if (score >= 80)
    printf("良好");
else
    printf("及格");

// switch语句
switch (day) {
    case 1: printf("星期一"); break;
    case 2: printf("星期二"); break;
    default: printf("其他");
}
```

### 3.2 循环结构
```c
// for循环
for (int i = 0; i < 10; i++) {
    printf("%d ", i);
}

// while循环
while (count < 5) {
    count++;
}

// do-while循环
do {
    sum += i;
    i++;
} while (i <= 100);
```

### 3.3 跳转语句
- `break`：跳出循环或switch
- `continue`：结束本次循环，继续下一次
- `return`：从函数返回
- `goto`：无条件跳转（不推荐使用）

## 4. 函数

### 4.1 函数定义
```c
// 函数声明
int add(int a, int b);

// 函数定义
int add(int a, int b) {
    return a + b;
}

// 无返回值函数
void printHello() {
    printf("Hello\n");
}
```

### 4.2 函数参数传递
- **值传递**：形参改变不影响实参
- **地址传递**：通过指针传递，可修改实参值

```c
// 值传递
void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

// 地址传递
void swapPtr(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

### 4.3 递归函数
```c
// 阶乘
int factorial(int n) {
    if (n <= 1)
        return 1;
    return n * factorial(n - 1);
}

// 斐波那契数列
int fibonacci(int n) {
    if (n <= 1)
        return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

## 6. 指针

### 6.1 指针基础
```c
// 指针声明
int *ptr;
int a = 10;
ptr = &a;  // 指向a的地址

// 访问指针值
printf("%d", *ptr);  // 输出10
*ptr = 20;           // 修改a的值
```

### 6.2 指针与数组
```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;  // 指针指向数组首地址

// 以下等价
arr[1] == *(p + 1)
&arr[1] == p + 1
```

### 6.3 指针与函数
```c
// 指针作为参数
void modify(int *p) {
    *p = 100;
}

// 指针作为返回值
int* getArray() {
    static int arr[5] = {1, 2, 3, 4, 5};
    return arr;
}
```

### 6.4 动态内存分配
```c
#include <stdlib.h>

// malloc分配
int *arr = (int*)malloc(5 * sizeof(int));

// calloc分配
int *arr2 = (int*)calloc(5, sizeof(int));

// realloc重新分配
arr = (int*)realloc(arr, 10 * sizeof(int));

// free释放
free(arr);
arr = NULL;
```

## 7. 结构体与共用体

### 7.1 结构体
```c
// 结构体定义
struct Student {
    char name[50];
    int age;
    float score;
};

// 结构体变量
struct Student stu1 = {"张三", 20, 95.5};
stu1.age = 21;  // 访问成员

// 结构体指针
struct Student *p = &stu1;
p->age = 22;  // 通过指针访问
```

### 7.2 共用体
```c
union Data {
    int i;
    float f;
    char c;
};

// 所有成员共享同一内存
union Data d;
d.i = 10;
d.f = 3.14;  // 此时d.i的值不确定
```

### 7.3 枚举
```c
enum Color {
    RED,
    GREEN,
    BLUE
};

enum Color c = RED;
```

## 8. 文件操作

### 8.1 文件打开与关闭
```c
FILE *fp;

// 打开文件
fp = fopen("data.txt", "r");  // 只读模式
fp = fopen("data.txt", "w");  // 写入模式
fp = fopen("data.txt", "a");  // 追加模式

// 关闭文件
fclose(fp);
```

### 8.2 文件读写函数
```c
// 字符读写
fgetc(fp);        // 读取一个字符
fputc(ch, fp);    // 写入一个字符

// 字符串读写
fgets(str, n, fp);    // 读取一行
fputs(str, fp);       // 写入字符串

// 格式化读写
fscanf(fp, "%d", &num);
fprintf(fp, "%d", num);

// 二进制读写
fread(buffer, size, count, fp);
fwrite(buffer, size, count, fp);
```

### 8.3 文件定位
```c
fseek(fp, 0, SEEK_SET);   // 文件开头
fseek(fp, 0, SEEK_CUR);   // 当前位置
fseek(fp, 0, SEEK_END);   // 文件末尾

ftell(fp);                 // 返回当前位置
rewind(fp);               // 回到文件开头
```

## 10. 常见考点

### 10.1 指针易错点
```c
int *p;         // 野指针，未初始化
*p = 10;        // 错误！解引用野指针

char *str = "Hello";
str[0] = 'h';  // 错误！字符串常量不可修改
```

### 10.2 数组名的本质
```c
int arr[5];
sizeof(arr);    // 20，整个数组的大小
arr;            // 数组首元素的地址
&arr;           // 整个数组的地址
```

### 10.3 函数指针
```c
// 函数指针声明
int (*funcPtr)(int, int);

// 赋值
funcPtr = add;

// 调用
int result = funcPtr(3, 5);
```

### 10.4 指针数组与数组指针
```c
int *arr[5];    // 指针数组：5个int指针的数组
int (*arr)[5];  // 数组指针：指向含5个int的数组的指针
```
