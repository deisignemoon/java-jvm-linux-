# C语言基本概念和语法

## 1. C语言概述

### 1.1 C语言特点
- **简洁紧凑**：关键字少，语法简洁
- **运算符丰富**：34种运算符
- **数据类型丰富**：整型、浮点型、字符型、数组、指针、结构体等
- **结构化语言**：支持顺序、选择、循环结构
- **可移植性好**：可直接访问物理地址
- **生成代码效率高**

### 1.2 C语言程序结构
```c
#include <stdio.h>  // 预处理指令

int main()          // 主函数
{
    printf("Hello, World!\n");  // 语句
    return 0;       // 返回值
}
```

### 2.1 基本数据类型

## 3. 控制结构

### 3.1 选择结构
```c
// if-else语句
if (score >= 90)

else if (score >= 80)
```

### 3.2 循环结构
```c

for (int i = 0; i < 10; i++) {
    printf("%d ", i);

// while循环
while (count < 5) {
```

### 3.3 跳转语句

## 4. 函数

### 4.1 函数定义
```c
// 函数声明
int add(int a, int b);

// 函数定义
int add(int a, int b) {
    return a + b;
}

// 无返回值函数
void printHello() {
    printf("Hello\n");
}
```

### 4.2 函数参数传递
- **值传递**：形参改变不影响实参
- **地址传递**：通过指针传递，可修改实参值

```c
// 值传递
void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

// 地址传递
void swapPtr(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

### 4.3 递归函数
```c
// 阶乘
int factorial(int n) {
    if (n <= 1)
        return 1;
    return n * factorial(n - 1);
}

// 斐波那契数列
int fibonacci(int n) {
    if (n <= 1)
        return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

## 6. 指针

## 11. C++语法

### 11.1 C++程序结构
```cpp
#include <iostream>   // C++输入输出流头文件
using namespace std;  // 使用标准命名空间

int main() {
    cout << "Hello, World!" << endl;  // 输出
    // cin >> num;                    // 输入
    return 0;

```

### 11.2 C++与C的区别
- **输入输出**：`cin`/`cout` 代替 `scanf`/`printf`
- **引用**：`int &r = a;` 代替指针传递
- **new/delete**：代替 `malloc/free`
- **面向对象**：类、封装、继承、多态
- **函数重载**：同名函数参数不同
- **默认参数**：`void func(int a, int b = 10);`
- **STL**：标准模板库（vector、map、string等）

### 11.3 引用
```cpp
// 引用声明：引用必须初始化，且不能改变绑定
int a = 10;
int &r = a;   // r是a的别名
r = 20;       // 修改r即修改a，a变为20

// 引用作为函数参数（比指针更安全）
void swap(int &x, int &y) {
    int temp = x;
    x = y;
    y = temp;
}

// 引用作为返回值
int& getMax(int arr[], int n) {
    int idx = 0;
    for (int i = 1; i < n; i++)
        if (arr[i] > arr[idx]) idx = i;
    return arr[idx];  // 返回引用，可修改
}
```

### 11.5 函数重载与默认参数

### 11.6 类与对象
```cpp
class Student {
private:          // 私有成员（默认private）
    string name;
    int age;

public:           // 公有成员
    // 构造函数：与类同名，无返回值
    Student() : name(""), age(0) {}              // 默认构造
    Student(string n, int a) : name(n), age(a) {} // 带参构造

    // 析构函数：~类名，对象销毁时自动调用
    ~Student() {}

    // 成员函数
    void display() {
        cout << name << " " << age << endl;
    }

    int getAge() const;  // const成员函数，不修改成员
};

// 成员函数类外定义
int Student::getAge() const {
    return age;
}

// 创建对象
Student stu1;                  // 栈上对象
Student stu2("张三", 20);       // 带参构造
Student *p = new Student();    // 堆上对象
delete p;                      // 手动释放
```

### 11.7 封装、继承与多态
```cpp

    void speak() override {         // override重写
        cout << "汪汪" << endl;
    }

Animal *a = new Dog();

delete a;

// 纯虚函数与抽象类
```

### 11.10 C++常见考点
```cpp
// 引用与指针的区别
int a = 10;
int *p = &a;   // 指针：可空、可改指向、可多级
int &r = a;    // 引用：非空、不可改、无多级

// 深拷贝与浅拷贝
class Arr {
    int *data;
    int n;
public:
    Arr(int n) : n(n) { data = new int[n]; }
    ~Arr() { delete[] data; }

    // 拷贝构造函数（深拷贝）
    Arr(const Arr &other) : n(other.n) {
        data = new int[n];
        for (int i = 0; i < n; i++) data[i] = other.data[i];
    }

    // 赋值运算符重载（深拷贝）
    Arr& operator=(const Arr &other) {
        if (this != &other) {
            delete[] data;
            n = other.n;
            data = new int[n];
            for (int i = 0; i < n; i++) data[i] = other.data[i];
        }
        return *this;
    }
};
```
